# Cap Finance

Application web de suivi du master en finance d'entreprise (octobre 2026 – septembre 2028) : apprentissage, ressources vérifiées, certifications, candidatures de stage et d'alternance, compétences et frise.

Page statique unique (`index.html`), sans dépendance ni build. Les données (cases cochées, statuts, candidatures) sont enregistrées dans le navigateur (`localStorage`).
